# 📋 기능 명세서: AI 응답 코드 블록 [원클릭 복사] 및 툴바 (F2-12)

- **작성일**: 2026-07-30
- **상태**: 사용자 검토 및 개발 시작 대기
- **대상 모듈**: `workmate-vue` (`src/common/utils/markdown.ts`, `src/modules/chat/components/MessageBubble.vue`)

---

## 1. 🎯 사용자 시나리오

1. 사용자가 채팅에서 AI로부터 코드 예시가 포함된 마크다운 응답(예: Java, TypeScript, SQL 등)을 받는다.
2. 각 코드 블록(`pre > code`) 상단 툴바에 코드의 언어(Language) 명칭과 **[복사] (Copy)** 버튼이 표시된다.
3. 사용자가 **[복사]** 버튼을 클릭하면 해당 코드 블록의 전체 코드가 클립보드에 바로 복사되며, 버튼 아이콘이 체크(Check) 모양과 "복사됨!" 문구로 2초간 변경된다.

---

## 2. 📑 상세 요구사항

| ID | 요구사항 | 상세 설명 및 기준 |
| :--- | :--- | :--- |
| **F2-12a** | 코드 블록 툴바 렌더링 | 마크다운 코드 블록(````lang ... ````) 상단에 코드 언어 태그와 복사 버튼 툴바 배치 |
| **F2-12b** | 클립보드 복사 연동 | `navigator.clipboard.writeText()` API 사용, 태그 제외 순수 코드 텍스트만 복사 |
| **F2-12c** | 시각적 피드백 제공 | 복사 성공 시 복사 아이콘 ➔ 체크 아이콘(`Check`)으로 전환 및 "복사됨!" 텍스트 2초 노출 후 복구 |
| **F2-12d** | 스트리밍 및 반응형 대응 | 스트리밍이 완료된 마크다운 렌더링 시점에 즉시 이벤트 바인딩 및 반응형 스타일 적용 |

---

## 3. 🏗️ 구현 설계 방안

- **방안 A (Markdown-It 커스텀 렌더러 + 이벤트 위임 방식)**:
  - `markdown.ts`에서 코드 블록 HTML을 생성할 때 상단 툴바 HTML(`code-header`, `copy-btn`, `code-lang`) 구조로 래핑 렌더링.
  - `MessageBubble.vue`에서 렌더링 후 `.copy-btn` 클릭 이벤트를 위임(Event Delegation) 처리하여 클립보드 복사 및 체크 상태 토글.
